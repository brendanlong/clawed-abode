# Settings UI

- Every settings card is a `shared/SettingsCard` (title, description, `isLoading`); every free-text setting is a `shared/EditableTextSetting`; every model field is a `shared/ModelOverrideField` (edit/save/clear) or, for plain form state, `shared/ModelCombobox`.
- Edit-in-place fields take the tRPC `useMutation` result as `mutation` (`shared/save-mutation.ts`) and render `mutation.error`. Never keep error text in `useState` — React Query already resets it on the next `mutate`, and the fields call `mutation.reset()` when the editor opens or closes.
- Global-settings cards live in `global/`; `GeneralTab` only composes them.
- The routers hand back secret values already masked (`••••••••`), so a form must never echo the value it was given back to a set-mutation — submit `''` for an untouched secret, which is the server's "keep the stored value" protocol (`doc/settings.md`). Sending the mask overwrites the real secret with the bullets.
- That protocol keys off the **submitted** `isSecret`, so `''` only means "keep" when the submission is still secret — [`keepsStoredSecret`](../../lib/key-value-entries.ts), which also decides whether a field shows the `(unchanged)` placeholder. Everywhere else a blank value must be rejected, including when the user flips Secret off on a stored secret. Clearing a value is never "delete the row" — rows have their own remove button. `KeyValueListEditor` rows go through `buildKeyValueRecord` in the same file; use it rather than re-deriving any of this.
- `SettingsListEditor` forms and rows wrap their injected promise functions (`EnvVarMutations`, `McpServerMutations`) in TanStack `useMutation`, and forms throw validation errors from `mutationFn`. Per-item state lives in a row component (`renderRow` + `SettingsListRow`), not in the section.
- `SettingsListEditor` calls `onUpdate()` itself after a delete resolves; don't also hang `onSuccess` on the delete mutation or every delete refetches twice.
- Never render a list fed by browser-reported data (voices, fonts, devices) as a `Select`: a Radix `Select` mounts every item even while closed, and Firefox with speech-dispatcher once reported ~15,000 voices, which froze the Settings page for over a minute. Use the capped, searchable `SearchableCombobox`.
